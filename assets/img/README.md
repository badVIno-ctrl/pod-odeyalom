# Картинки

Положите PNG (можно WebP/JPG) с именем ключа в эту папку — игра возьмёт её вместо нарисованной заглушки.
Код править не нужно, достаточно обновить страницу. Если файла нет или он битый — снова будет заглушка, без ошибок.

**Полное ТЗ для художника — `docs/художнику/`**: все ключи (`текстуры.json`), листы с нынешними заглушками и PNG-шаблоны
в точном размере (`шаблоны/`). Заменить можно любой ключ из `assets/manifest.json`, не только перечисленные ниже.

| Ключ | Размер, px | Что это и как привязано |
|---|---|---|
| `menu_bg` | 1920×1080 | Меню: спальня в сумерках, паутина в углу. Слева темнее — там текст |
| `road_far` | 3840×1080 | Пролог: дальний слой (небо, лес), день. Прокручивается влево на 380 px |
| `road_mid` | 3840×1080 | Средний слой (ёлки, сугробы), прозрачный верх. Прокрутка 1000 px |
| `road_front` | 3840×1080 | Ближний слой (край дороги), прозрачный верх. Прокрутка 1880 px |
| `road_far_storm` | 3840×1080 | Дальний слой в пургу (плавно заменяет `road_far`) |
| `porch` | 1920×1080 | Крыльцо, дверь закрыта. Дверь — около x = 960, низ двери y ≈ 860 |
| `porch_door_open` | 1920×1080 | То же крыльцо, дверь открыта, тёплый свет |
| `bedroom_day` | 1920×1080 | Спальня днём **без** кровати с мальчиком и без мамы. Окно 470,170 (420×420), тумбочка 930..1110, верх y = 700, дверь слева |
| `bedroom_night` | 1920×1080 | Та же спальня ночью |
| `web_window` | 460×460 | Паутина на окно (комната C), прозрачный фон, центр окна (680, 380) |
| `thermometer_item` | 240×64 | Градусник на тумбочке (масштаб 0,5) |
| `jam` | 170×200 | Банка варенья; низ банки ставится на тумбочку (масштаб 0,55) |
| `socks`, `potato_pot` | 220×150, 260×210 | Награды следующих дней |
| `boy_bed_healthy` / `_sick` / `_very_sick` / `_critical` | 860×540 | Кровать **вместе** с мальчиком. Привязка — низ по центру, ставится в (1470, 1000) |
| `pair_walk` | 2160×480 | Мама и мальчик идут: 6 кадров по 360×480 в одну строку, **без шарфа**. Низ кадра — земля |
| `scarf` | 230×90 | Шарф мальчика, крепится к шее около (262, 300) внутри кадра `pair_walk` |
| `mom_stand` | 380×860 | Мама в полный рост, низ по центру ставится в (800, 1020) |
| `spider_idle`, `spider_grin` | 480×340 | Паук висит головой вниз; нить крепится в середину верхнего края (12 px от верха) |
| `spider_corner` | 240×170 | Маленький паук для меню, нить — середина верхнего края |

Пока `spider_idle.png` нет, паук собирается из частей и шевелит лапами кодом. С настоящей картинкой он
покачивается целиком (масштабом), ухмылка — `spider_grin.png`.
