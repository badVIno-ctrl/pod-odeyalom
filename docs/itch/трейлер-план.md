## Как снять

`tools/capture/capture.mjs` записывает игру кадр в кадр (виртуальное время: `performance.now`, таймеры и
`requestAnimationFrame` идут только по команде, поэтому медленная машина не роняет кадры):
`rec(имя, секунды, [{ t, fn }])` — запись кадров в JPEG, `ff(условие)` — перемотка без отрисовки, `still(имя)` —
PNG. Реплики записываются в `shots.json` со временем начала — по ним ставятся голоса при монтаже.
Пример сценария — `tools/capture/shots-stills.mjs` (все пять дней, финал, титры).
Склейка: `ffmpeg -framerate 30 -i кадр/%05d.jpg …`, звук — музыка + реплики по времени из `shots.json`.
