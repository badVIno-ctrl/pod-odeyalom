# «Под одеялом» — ТЗ художнику

Вся графика игры сейчас нарисована кодом (временная). Любую картинку можно заменить файлом — **без правки кода**: положить `assets/img/<ключ>.png` и обновить страницу. Размер — ровно как в таблицах ниже: по нему считаются точки крепления и раскладка.

В этой папке: `шаблоны/<группа>/<ключ>.png|jpg` — текущие картинки в точном размере (рисовать поверх или рядом), `листы/<группа>.jpg` — обзор группы с подписями, красный крестик — пивот (точка крепления к кости), `текстуры.json` — тот же список для программ.

## Стиль

- Детская книжка-«перекладка»: плоская заливка, мягкие градиенты, тёмный тёплый контур `#24170f` толщиной 4–5 px (на деталях кукол — 3,5–4 px). Без фотофактуры, без резкого блика и неона.
- Палитра: ночь — тёмно-синий `#0f1626`…`#2c3d5b`, дерево — `#7a5638`/`#654b3a`, бумага — `#f3ebdd`, тёплый акцент — `#f2a65a`, огонь Огнёвки — `#fcd284`…`#c4402a`, паук — `#8a5a33` / полосы `#4e2f17` / голова `#9a673c`.
- Свет: лампа на тумбочке тёплая, окно холодное синее. Тени мягкие, без чёрного.
- Персонажи — круглые, добрые, читаются с одного взгляда на телефоне. Тихон страшный только размером: глаза большие и тёплые.
- Не делать: свечение, искры и блёстки «для эффекта», грязь и ужасы, сгенерированные нейросетью картинки (нужна авторская рисованная графика).

## Формат сдачи

- PNG, 8 бит на канал, sRGB, с прозрачностью; фоны можно в JPG/WebP (то же имя ключа).
- Размер — ровно как у шаблона (1×, экран 1920×1080). Детали кукол — с прозрачными полями как в шаблоне; пивот (красный крестик на листе) должен остаться на том же месте.
- На суставах детали заходят друг на друга: концы рукавов и ног скруглены, не обрезать по линии сгиба.
- Варианты одной детали (глаза, рты, головы по состояниям) — один размер и одно положение на листе, меняется только рисунок.
- Надписей на картинках не делать: игра двуязычная (русский и английский), все надписи рисует код.
- Исходники (PSD/Krita/Procreate) по слоям — отдельно, с теми же именами.

## Как проверить в игре

1. `npm install`, затем `npm run dev` (или «РАЗРАБОТКА (Node.js).bat»). Файлы класть в `assets/img/`, обновить страницу.
2. Стенды: `?lab=parts` — все детали кукол с пивотами; `?lab=rig` — собранные мальчик и мама в позах (рука тянется за мышкой); `?lab=world` — Огнёвка и сюжетные предметы; `?lab=drawings` — детские рисунки; `?lab=pov&mode=medicine` (`tea`, `doctor`, `socks`, `towel`) — сцены от первого лица; `?labels=1` — подписи ключей на заглушках.
3. `?debug=1` — клавиши 1…5 переносят в нужный день, W/L — выиграть/проиграть партию, S — пропустить сцену.
4. Если размер не совпал, игра напишет в консоли браузера: `[assets] ключ: картинка W×H, нужно w×h`.

## Очерёдность

1. **Тихон, мальчик, мама, кровать** — они в кадре всю игру.
2. **Фоны спальни** (день, ночь, рассвет), **Огнёвка**, пролог (дорога, крыльцо, мама с мальчиком).
3. Тайная глава «Аня», сцены от первого лица, мелкий реквизит.

Всего картинок: 151. Ниже — все, по группам.

## Мальчик — детали куклы (25, очередь 1)

Семь лет, русые волосы, пижама цвета топлёного масла с тонкой терракотовой полоской. Лежит в кровати; кукла собирается из деталей на костях (голова, глаза, рот, плечо, предплечье, кисть). Глаза и рот — отдельные картинки поверх головы, поэтому на голове их **нет**. Голова и кисть — в четырёх состояниях по температуре: `healthy` ≤ 37,5°, `sick` ≤ 38,9°, `very_sick` ≤ 39,7° (мокрое полотенце на лбу, испарина), `critical` — выше (сильный румянец, бледность вокруг). Губы двигаются по громкости голоса: `closed` → `half` → `open` → `O`.
