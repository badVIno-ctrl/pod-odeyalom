# Звук и музыка: исходники

Здесь лежат скрипты, которыми собраны все звуки из `assets/audio/sfx/` (кроме голосов) и вся музыка
из `assets/audio/music/`. Для игры они не нужны — только чтобы что-то поменять и пересобрать.

| Файл | Что делает |
|---|---|
| `build_sfx.py` | звуки: обработка CC0-записей (обрезка, фильтры, комната, громкость) и синтез (сирена, печка, гул, звонок, снегирь, мотор, огнёвка, звуки интерфейса…) |
| `build_music.py` | 8 музыкальных тем и стингеры `win`, `lose`, `daycard`, `musicbox` |
| `score.py` | ноты: колыбельная тема (ре мажор, 3/4), тема Тихона (си минор) и их варианты |
| `build_music2.py` | музыка wow-пакета: ночь слоями (по нитям паутины), «паутинная арфа», песня для титров «Ниточка», радио бабы Вали |
| `song.py` | «Ниточка» для записи голоса: текст по слогам, MIDI, ноты (MusicXML → PDF), минус и мелодия отдельно → `docs/песня/` |
| `sampler.py`, `synth.py`, `au.py` | сэмплер по VCSL, синтез инструментов, фильтры, ревербератор, громкость по BS.1770 |
| `fetch_sources.py`, `vcsl-files.txt` | скачивание исходных записей и сэмплов в `сырьё/` |

## Как пересобрать

Нужны Python 3.10+, `numpy`, `scipy` и `ffmpeg` в PATH.

```
python3 fetch_sources.py          # один раз: ≈ 550 МБ в _исходники/звук/сырьё/ (или SFX_SRC=<папка> для готового сырья)
python3 build_sfx.py              # все звуки; или выборочно: python3 build_sfx.py sea stove
python3 build_music.py            # вся музыка и стингеры
python3 build_music2.py           # ночные слои, паутинная арфа, титры, радио
python3 song.py all; python3 song.py audio   # песня «Ниточка»: ноты, MIDI, минус (см. docs/песня/README.md)
```

Результат сразу пишется в `assets/audio/`, рядом в `review/` появляются спектрограммы для проверки.
Громкость выровнена: короткие звуки — по пиковой кратковременной громкости, петли — по интегральной (LUFS).
Папку `сырьё/` в архив игры класть не нужно.

Все источники — CC0, список с авторами в `docs/credits.md`.
