# Исходники (игра от этой папки не зависит)

- `ТЗ.txt` — техническое задание.
- `паук-референс.png` — образ паука.
- `online-heckers-main.zip`, `seabattle-main.zip` — ваши шашки и морской бой. Из них взята логика сложности ИИ
  (см. `docs/notes.md`, раздел 4).
- `озвучка-старая/` — старые страницы-прослушки и WAV. Там другой сценарий: укус, врач. В игре они не используются.
  `voice/scene-dialogue.txt` — полный сценарий всех дней. Из него взят порядок мини-игр.
- `голоса/` — сценарий реплик с ударениями, скрипт синтеза Silero, прежняя озвучка Qwen. Нужны, чтобы озвучить новые
  реплики тем же голосом.

Если папка не нужна, её можно удалить.
