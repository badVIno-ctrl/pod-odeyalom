# Голоса: как озвучить новую реплику тем же голосом

Все 276 реплик синтезированы **Silero TTS** `v5_2_ru` локально, одним прогоном `synth2.py` (одинаковые настройки для всех) (лицензия модели CC BY-NC-SA 4.0: только некоммерческое использование).
Это временная озвучка: для выпуска её стоит заменить записью живых актёров (тексты и ID остаются те же).

## Файлы

- `lines.py`: все реплики. Формат `a(ID, персонаж, пресет, текст субтитра, текст для синтеза)`.
  В тексте для синтеза `+` ставится перед ударной гласной: «сын+ок». Паузы задаются многоточием, запятыми и точками.
- `synth2.py`: синтез и обработка. Голос и темп по пресету (SSML), короткая тишина в начале (первый звук не обрезается),
  срез низов, подъём разборчивости 2–4 кГц, лёгкая «комната», выравнивание громкости до −18 LUFS. Результат: `assets/audio/voice/<ID>.mp3`.
  Запуск: `python3 synth2.py` (все реплики), `python3 synth2.py M05 B03` (только эти) или `python3 synth2.py --laugh` (смех паука).
  Нужны Python 3, `torch`, `numpy`, `scipy`, `soundfile`, `pyloudnorm` и ffmpeg. Пути задаются переменными `ROOT`, `OUT`, `RAW`.
- `build_data.py`: собирает `data/dialogue.json` (субтитры), `data/lipsync.json` (движение губ по громкости) и `script.tsv`.
  Запускать после синтеза: `python3 build_data.py`.
- `check.py`: проверка разборчивости распознаванием речи (faster-whisper): `python3 check.py <папка с wav> [ID ...]`.
- `script.tsv`: таблица всех реплик (собирается автоматически, для чтения и правки в табличном редакторе).

## Пресеты

| Пресет | Голос | Темп | Где |
| --- | --- | --- | --- |
| `mom`, `mom_out` | baya | medium | мама в комнате и на улице |
| `mom_slow` | baya | slow | длинные важные реплики мамы (M05) |
| `mom_soft` | baya, ниже | slow | ночные и тихие реплики |
| `boy`, `boy_out` | kseniya, x-high | slow | мальчик |
| `boy_weak` | kseniya, x-high | x-slow, тише | мальчику очень плохо |
| `spider`, `spider_out` | aidar, low | slow | Тихон |
| `spider_soft` | aidar, low (как `spider`), тише | slow | тихая реплика Тихона в счастливом финале (S124) |
| `doctor`, `medic` | eugene | 70% | врач и фельдшеры |

## Новая реплика

1. Добавить строку в `lines.py`.
2. `python3 synth2.py ID`, затем `python3 build_data.py`.
3. `node tools/make-voice-page.mjs` обновит страницу «ПРОСЛУШАТЬ ГОЛОСА.html».

`qwen-старые/`, `refs/`, `voices.json`, `master.py`: прежняя озвучка ранней версии (Qwen3-TTS, Apache-2.0), оставлена для истории.

## Смех паука

`assets/audio/sfx/spider_laugh.mp3` — тем же голосом, что и реплики Тихона: Silero `aidar`, пресет `spider`,
SSML `<prosody pitch="low" rate="slow">Х+е-х+е-х+е-х+е.</prosody>`, обработка `process()` из `synth2.py`.
Раньше смех был отдельной синтетической записью другого тембра, и у паука звучало «два голоса».

## Для живой озвучки

- `studio_script.py` — сценарий студийной записи: `docs/озвучка/СЦЕНАРИЙ ЗАПИСИ.md` и `сценарий-записи.xlsx`
  (кастинг, тексты с ударениями, подача и контекст каждой реплики). Запуск из корня проекта:
  `python3 _исходники/голоса/studio_script.py`.
- `directions.py` — кастинг (`CAST`) и подача каждой реплики (`NOTE`), источник для сценария.
- Готовый дубль кладётся как `assets/audio/voice/<ID>.mp3`, ID реплики = имя файла.
